## 这个仓库怎么用

- `main` 分支保持可运行状态，每个项目完成后合并进来
- 每个项目目录下有一份 `README.md`，写清楚「为什么这么设计」而不只是「怎么用」
- 提交信息统一用 `feat:` / `fix:` / `docs:` / `chore:` 前缀
