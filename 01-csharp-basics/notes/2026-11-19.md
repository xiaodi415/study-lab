\# LINQ 延迟执行



\## 实验结论

1\. 定义 Where 查询时不执行，遍历时才执行（拉取式，要一个算一个）

2\. 遍历两次 = 源执行两次；IQueryable 会发两次 SQL

3\. ToList() 是终结操作，立即物化并固化结果，之后遍历不再碰源

4\. 查询会捕获外部变量，定义后改变量会影响结果（与闭包同源）



\## 什么时候必须 ToList

\- 多次遍历

\- 跨 await 使用

\- 遍历中要修改源集合

\- 需要稳定快照



\## 追溯系统里的坑

var q = db.Logs.Where(...);

q.Count();        // SQL 第 1 次

foreach (var x in q) // SQL 第 2 次

→ 改成 ToList 后只查一次



\## 面试一句话

LINQ 的 IEnumerable 查询延迟执行，终结操作才真正查询；

重复遍历会重复执行（IQueryable 重复发 SQL）；

多次使用要先 ToList 物化；延迟执行会捕获变量，改变量影响结果。
