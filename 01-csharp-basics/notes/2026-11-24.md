\# async/await 与死锁



\## 复现条件

必须有 SynchronizationContext（UI 线程）；

控制台默认没有，所以直接 .Result 不会死锁 → 需要脚手架模拟。



\## 死锁链路

UI 线程 .Result 阻塞 → Task 的续体要回 UI 线程 → 队列没人处理 → 双方互等



\## 三种解法

1\. async 到底（正解）

2\. ConfigureAwait(false)（库代码用，续体不回 UI，不能碰控件）

3\. Task.Run(...).Result（掩耳盗铃）



\## 本质

async 不开线程；await 挂起方法不挂起线程；

续体默认回原上下文 —— 这就是死锁的根。



\## 上位机

事件处理器可以 async void，其他一律 async Task。



\## 面试一句话

async 在第一个未完成 await 处返回；续体回捕获的 SyncContext；

UI 线程上 .Result 会死锁；正解是一路 async 到底。
