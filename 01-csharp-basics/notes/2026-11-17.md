\# 事件 event



\## 三个结论

1\. event = 委托字段 + 访问控制，外部只能 += / -=，不能赋值和调用（CS0070）

2\. 没有订阅者时事件为 null，必须用 ?.Invoke 触发

3\. 多线程下要先拷贝到局部变量再调用，避免判断后被退订



\## 标准写法

public event EventHandler<T>? Xxx;

protected virtual void OnXxx(...)

{

&#x20;   var h = Xxx;

&#x20;   h?.Invoke(this, new T(...));

}



\## 三个坑

1\. 没订阅者 → 直接调用会 NRE，用 ?.

2\. 多线程 → 先拷局部变量

3\. 订阅者抛异常 → 后续订阅者收不到，各自 try/catch



\## lambda 退订

lambda 每次都是新委托实例，-= 删不掉；

必须先存到 EventHandler<T> 变量里再 -=。



\## 工作关联

SerialPort.DataReceived、WPF Click、Timer.Elapsed 都是事件。



\## 面试一句话

event 是委托加访问控制，外部只能订阅/退订；触发要判空（?.Invoke），

多线程要先拷贝局部变量，订阅者异常会中断后续通知。
