\# 泛型与约束



\## 三个结论

1\. 没有约束时 T 只能当 object 用，new T() 和访问成员都编译不过

2\. 约束 = 告诉编译器 T 具备的能力；约束越多能用的成员越多，能传的类型越少

3\. C# 泛型是运行时特化，每种 T 是不同类型，源码只有一份



\## 约束清单

class / struct / new() / 基类 / 接口 / notnull / unmanaged

书写规则：class 或 struct 必须在第一个，new() 必须在最后



\## 泛型 vs object

类型安全（编译期检查）+ 零装箱（11/10 实测 8 倍内存差）+ 代码复用



\## 项目里怎么用

Repository<T> where T : class, IEntity, new()

→ 数据访问层，Controller → Service → Repository → EF Core



\## 面试一句话

泛型提供类型安全、零装箱和代码复用；约束声明 T 具备的能力，

class 限引用类型、new() 才能 new T()、接口约束才能用接口成员；

class/struct 放首位，new() 放末位。
